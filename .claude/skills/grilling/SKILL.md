---
name: grilling
description: Interview relentlessly about a plan or design, one decision at a time.
---

Interview the project owner about every important branch of the plan until there is a shared understanding.

Rules:

- Ask exactly one question at a time.
- For each question, include the recommended answer.
- If code or docs can answer the question, inspect them instead of asking.
- When the answer reveals a terminology conflict, resolve it in `CONTEXT.md`.
- When the answer reveals a product or architecture mismatch, update the relevant docs or propose an ADR.
- Prefer concrete scenarios over abstract opinions.
