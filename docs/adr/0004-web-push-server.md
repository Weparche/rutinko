# Web Push server for closed-browser reminders

Reliable reminders on mobile with the browser closed require server-sent Web Push, so Rutinko now has a minimal backend: the `worker/` Cloudflare Worker (`rutinko-push`, cron every 5 min). Each device anonymously POSTs its push subscription plus a sanitized snapshot of tasks/settings/state to `/api/sync` (keyed by a hash of the push endpoint — no accounts, no login, which keeps the ADR 0001 spirit). The cron computes due routines in the device's timezone, sends one grouped push per device (VAPID + `@block65/webcrypto-web-push`), tracks `lastNotified` server-side, and deletes subscriptions that return 404/410. The service worker's local reminder engine (ADR 0003) remains as the fast path while the app is open; the push path covers closed-browser delivery on Android and iOS (installed PWA, iOS 16.4+). VAPID private key lives in a Worker secret; subscriptions live in KV with occurrence maps pruned to 3 days.
